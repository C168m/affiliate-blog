# Amazon Product Review Template
**Based on: FatStacks $2K/mo case study + Partnerkin $19K/mo case study**

## Article Type: Single Product Review
**Best for**: "{product_name} Review 2026 -- Is It Worth It?"

### Structure (2000-2500 words)

1. **Quick Verdict Box** (100 words)
   - TL;DR: Who it is for, rating out of 5, best feature
   - Use as Google featured snippet bait

2. **Introduction** (150 words)
   - Hook: relatable problem the product solves
   - Why this review matters (tested X hours, compared Y alternatives)

3. **What Is {product_name}?** (150 words)
   - Brief overview, target user, key specs
   - Amazon affiliate link #1 here (first 300 words)

4. **Unboxing & First Impressions** (200 words)
   - What is in the box, build quality, initial setup
   - Amazon image link embed

5. **Key Features Breakdown** (400 words)
   - Feature 1, Feature 2, Feature 3 (H3 each)
   - Natural product links interleaved

6. **Performance Testing** (300 words)
   - Real-world testing results
   - Comparison to advertised specs
   - Honest limitations

7. **Pros & Cons Table** (100 words)
   | Pros | Cons |
   |------|------|
   | ...  | ...  |

8. **Price & Value Analysis** (150 words)
   - Current price, value vs competitors
   - Amazon link #2

9. **Alternatives Comparison** (200 words)
   - Brief comparison with 2 alternatives
   - Each with affiliate link

10. **Final Verdict** (150 words)
    - Who should buy / who should skip
    - Strong CTA with Amazon link

11. **FAQ Section** (150 words)
    - 3-5 questions from "People Also Ask"

### Amazon Content Best Practices
- **Links per article**: 5-8 natural placements
- **Disclosure**: "As an Amazon Associate I earn from qualifying purchases." (top + near first link)
- **Image alt text**: Include target keyword
- **CTR optimization**: Comparison table rows into Amazon links, CTA button in verdict
- **Internal linking**: Link to related "best of" / comparison articles
