## 1. Intelligent Email Categorization with GPT-3.5

Small business owners get flooded with emails: customer inquiries, vendor quotes, spam, and internal notes. Let's build a classifier that routes emails to appropriate folders or Slack channels.

**Python Implementation:**

```python
import openai
import os
from typing import Dict, List

# Configure your API key
openai.api_key = os.getenv("OPENAI_API_KEY")

EMAIL_CATEGORIES = [
    "customer_support", 
    "vendor_inquiry", 
    "internal_memo", 
    "spam", 
    "invoice_related"
]

def classify_email(subject: str, body: str) -> Dict[str, str]:
    prompt = f"""
    Classify this email into exactly one category: {', '.join(EMAIL_CATEGORIES)}.
    
    Subject: {subject}
    Body: {body[:2000]}  # Truncate to save tokens
    
    Respond with JSON: {{"category": "category_name", "confidence": 0.95}}
    """
    
    response = openai.ChatCompletion.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.1,
        max_tokens=100
    )
    
    return eval(response.choices[0].message.content)  # Caution: use json.loads in prod

# Usage example
test_email = {
    "subject": "Urgent: Need help with order #12345",
    "body": "I placed an order three days ago and it hasn't shipped yet. Can you expedite?"
}

result = classify_email(test_email["subject"], test_email["body"])
print(f"Category: {result['category']}, Confidence: {result['confidence']}")
```

**Deployment tip:** Hook this into Gmail API or Outlook Graph API to automate folder assignment. For higher accuracy, fine-tune the model on 100 labeled emails from your inbox.

## 2. Automated Invoice Data Extraction from PDFs

Manual invoice processing costs small businesses 8-12 hours monthly. Use OCR + LLM to extract key fields.

**Workflow using PaddleOCR + GPT-4 Vision:**

```python
import pytesseract
from PIL import Image
import pdf2image
import openai
import re

def extract_invoice_data(pdf_path: str) -> dict:
    # Step 1: Convert PDF to images
    images = pdf2image.convert_from_path(pdf_path, dpi=300)
    
    # Step 2: OCR extraction
    text_blocks = []
    for img in images:
        text = pytesseract.image_to_string(img, lang='eng')
        text_blocks.append(text)
    
    full_text = "\n".join(text_blocks)
    
    # Step 3: GPT extraction of structured data
    prompt = f"""
    Extract the following from this invoice text. Return as JSON:
    - invoice_number (string)
    - vendor_name (string)
    - total_amount (float)
    - due_date (YYYY-MM-DD)
    - line_items (array of {description, quantity, unit_price, total})
    
    Invoice text:
    {full_text[:3000]}
    """
    
    response = openai.ChatCompletion.create(
        model="gpt-4-vision-preview",  # Note: costs more but handles complex layouts
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"}
    )
    
    return json.loads(response.choices[0].message.content)

# Batch process directory
import glob
invoices = glob.glob("./invoices/*.pdf")
for path in invoices[:10]:  # Process first 10
    data = extract_invoice_data(path)
    print(f"Invoice {data['invoice_number']} from {data['vendor_name']}: ${data['total_amount']}")
```

**Pro tip:** For better accuracy on handwritten invoices, fine-tune PaddleOCR using your specific invoice templates first.

## 3. Social Media Content Generator with Brand Voice

Small businesses need consistent posting but lack copywriting skills. Build a generator that maintains brand voice:

```python
from langchain.llms import OpenAI
from langchain.prompts import PromptTemplate
from langchain.chains import LLMChain
import json

class SocialMediaGenerator:
    def __init__(self, brand_guidelines: dict):
        self.llm = OpenAI(temperature=0.7, model="gpt-3.5-turbo-instruct")
        self.guidelines = brand_guidelines
        
        self.prompt_template = PromptTemplate(
            template="""
            You are a social media manager for {brand_name}.
            Brand voice: {tone}
            Target audience: {audience}
            
            Generate {count} social media posts about {topic} for {platform}.
            Each post must be under {char_limit} characters.
            Include 1-3 relevant hashtags.
            
            Return as JSON array: [{{"post": "text", "hashtags": ["#tag1"]}}]
            """,
            input_variables=["brand_name", "tone", "audience", "count", "topic", "platform", "char_limit"]
        )
        
        self.chain = LLMChain(llm=self.llm, prompt=self.prompt_template)
    
    def generate_posts(self, topic: str, platform: str = "instagram", count: int = 5):
        response = self.chain.run({
            "brand_name": self.guidelines["name"],
            "tone": self.guidelines["voice"],
            "audience": self.guidelines["audience"],
            "count": count,
            "topic": topic,
            "platform": platform,
            "char_limit": 280 if platform == "twitter" else 2200
        })
        return json.loads(response)

# Usage
brand = {
    "name": "GreenLeaf Organics",
    "voice": "Educational, friendly, sustainability-focused",
    "audience": "Eco-conscious millennials aged 25-40"
}

generator = SocialMediaGenerator(brand)
posts = generator.generate_posts("How to compost at home", "instagram", 3)
for p in posts:
    print(f"Post: {p['post']}\nHashtags: {', '.join(p['hashtags'])}\n")
```

**Automation pipeline:** Connect to Buffer or Hootsuite API to schedule generated posts automatically.
