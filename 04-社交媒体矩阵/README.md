# 04-社交媒体矩阵

## 🎯 职能
用AI自动化运营Twitter/X、Reddit、Pinterest、Medium，为数字产品导流。

---

## 🌍 四大导流渠道

### Twitter/X
- **策略**: AI生成行业干货推文 + 产品链接
- **频率**: 每日3-5条
- **工具**: Tweepy API + DeepSeek
- **变现**: 简介链接 → Gumroad

### Reddit
- **策略**: 在相关Subreddit提供价值回复
- **关键**: 先贡献再推广 (90%价值+10%链接)
- **工具**: PRAW API + Playwright
- **注意**: 每个Subreddit规则不同

### Pinterest
- **策略**: 产品图片Pin → 链接到Gumroad/Blog
- **优势**: 长尾流量，Pin存活数年
- **工具**: Pinterest API + Canva

### Medium
- **策略**: AI辅助写长文 → 结尾CTA → 产品链接
- **优势**: 自带SEO权重
- **变现**: Medium Partner Program + 产品链接

---

## 🛡 风控策略

| 平台 | 风险 | 对策 |
|------|------|------|
| Reddit | 被ban | 养号+贡献+低频 |
| Twitter | shadowban | 正常互动+不刷 |
| Pinterest | 限流 | 高质量图片 |
| Medium | 封号 | 原创度+人工润色 |
